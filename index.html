Nạp file cookies.txt

Nếu YouTube chặn IP hoặc yêu cầu đăng nhập đối với một số video nhất định, hãy xuất file cookies.txt từ trình duyệt của bạn và tải lên đây:

Kéo & thả file cookies.txt vào đây hoặc chọn file

Hướng dẫn lấy file cookies.txt trong 1 phút
  1. Cài đặt tiện ích mở rộng Get cookies.txt LOCALLY (hoặc Cookie-Editor) trên Chrome, Cốc Cốc hoặc Edge.
  2. Mở trang web youtube.com (đã đăng nhập tài khoản bất kỳ của bạn).
  3. Nhấp vào biểu tượng tiện ích → chọn Export as cookies.txt và tải file lên đây.
